Conectar con GitHub

La primera vez tienes que crear un "token" (una clave de acceso). Solo se hace una vez:

  1. Entra en github.com/settings/personal-access-tokens/new (con la cuenta de GitHub del club).
  2. Token name: pon lo que quieras, p. ej. Panel Resisbarna.
  3. Expiration: elige el plazo que prefieras (p. ej. 1 año).
  4. Repository access → Only select repositories → elige Resisbarna.
  5. Permissions → Repository permissions → busca Contents → ponlo en Read and write.
  6. Pulsa Generate token al final de la página.
  7. Copia el token que aparece (empieza por github_pat_) — solo se muestra una vez — y pégalo aquí abajo.

Este token solo se guarda en tu propio navegador y solo se usa para hablar directamente con GitHub. No lo compartas: funciona como una contraseña para modificar la web. Si crees que alguien más lo tiene, bórralo desde la misma página de GitHub y crea uno nuevo.
